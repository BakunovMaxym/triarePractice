# My App Frontend

This is a simple frontend for the backend in `my-nest-app`.

## Getting Started

```bash
cd my-app
yarn install
yarn dev
```

The app will run at [http://localhost:5173](http://localhost:5173).

## Features

- User registration and login
- List courses
- View course details
- List categories and sub-categories

> Update API URLs in `src/api.ts` if your backend runs on a different port.
